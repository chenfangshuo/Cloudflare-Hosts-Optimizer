# hosts 安全规则

这个工具对 hosts 的处理原则是：**能明确判断才改，判断不了就中止**。

## 标记

- 只接受“没有标记”或“恰好一对 BEGIN/END 且顺序正确”。
- 缺失 END、重复 BEGIN/END、嵌套、孤立 END → 中止并报告行号。
- 区块固定放在文件末尾，前后空行会规范化；其他行保持原样。

## 冲突检查

- **多别名行**：托管区块外，某行包含受管域名且有多个主机名 → 中止，要求人工拆分。
- **IPv6 映射**：受管域名已有 IPv6 条目 → 中止，避免“写了 IPv4 却仍走 IPv6”。
- **其他工具区块**：检测到 `# XXX BEGIN ... / # XXX END ...` 且其中包含受管域名 → 中止，
  不接管其他工具的条目。
- **编码**：只支持 ASCII / UTF-8（含 BOM）。UTF-16、GBK/ANSI → 拒绝改写，避免损坏原文件。

## 增量语义

- 验证成功 → 更新映射。
- 验证失败 → 默认保留上一次映射；只有明确 `1034/1003`（边缘 IP 受限）才自动丢弃。
- 连接失败/TLS/超时默认保留并告警，`-DropUnreachable` 才删除。
- 不在本次域名列表 → 默认保留，`-Prune` 才删除。
- 1034 回退胜出的是该域名自己的 DNS 记录时，动作是 **release**：删除托管条目、交还 DNS；
  区块外已有的旧条目/手工条目不会删除，仍会生效并告警。

## 备份

- 目录：`%ProgramData%\pt-cf-optimize\backup`（不可写时回退项目目录）。
- 非系统 `-HostsPath` 使用 `targets\<路径哈希>` 子目录；回滚时校验 manifest 的 `hostsPath`，
  避免沙箱备份被系统 hosts 的回滚选中。
- 文件名含时间戳和 GUID，附带 JSON 清单（pre/post 哈希）；按文件名选最近，
  不依赖 LastWriteTime。
- 保留最近 10 份 + 一份首次接管快照。

## 写入与回滚

- 写入：全局互斥锁 → 提交前哈希检查 → 临时文件 → 原子替换 → 读回校验 → 刷新 DNS。
- 如果 hosts 在最后一次写入后被其他程序改过，`-Rollback` 默认拒绝覆盖，`-Force` 才允许。
- `-Rollback` 不依赖 `domains.txt`，域名清单丢失时仍可恢复。
